# AICQ Assessment

AICQ Assessment Platform.

## Repository purpose

This repository contains the version-controlled application, Supabase
database definitions, server-side functions, configuration templates and
technical documentation for AICQ.

## Backend

Supabase project: AICQ project

The production database is not copied into GitHub. Only source definitions,
migrations, safe configuration templates and documentation belong here.

## Development

See `docs/architecture.md` and `docs/database-baseline.md`.

Never commit `.env` files, service-role credentials, passwords, API secrets,
participant records, or other production data.
